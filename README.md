# Nederwijk Roleplay

De officiële website van **Nederwijk Roleplay** — een Nederlandse/Belgische FiveM roleplay-community.

De website bevat informatie over de server, de Algemene Plaatselijke Verordening (APV), sollicitatiemogelijkheden en directe links naar onze Discord-community.

## Functies

* Moderne donkerblauwe Nederwijk-stijl
* Volledig responsive voor desktop en mobiel
* Geanimeerde interface en interactieve kaarten
* APV-pagina
* Sollicitatiepagina voor verschillende afdelingen
* Directe Discord-links
* Geschikt voor GitHub Pages
* Ondersteuning voor een eigen domein via `CNAME`

### Home

De hoofdpagina van Nederwijk Roleplay.

### APV

De regels en richtlijnen van Nederwijk Roleplay.

### Solliciteren

Sollicitatiemogelijkheden voor onder andere:

* Staff
* Politie
* Koninklijke Marechaussee
* Ambulance

De sollicitatieknoppen verwijzen rechtstreeks naar Discord.
